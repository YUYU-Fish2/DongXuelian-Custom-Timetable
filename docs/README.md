## 验证记录

2026-10-04 的 UI 验证使用 RMX3700 / Android 16（API 36），原始分辨率 1240 × 2772、密度 560、字体比例 100%。测试通过独立 `.validation` 包进行。354 / 360 / 393 / 411dp 宽度与 100% / 115% / 130% 字体组合在同一手机上模拟，不能视为四种硬件的兼容性认证。

| 记录 | 范围 |
| --- | --- |
| [初始真机验证](device-validation-2026-10-04.md) | Bugfix 阶段的 15 项真机检查与复跑方法 |
| [P2 状态矩阵](screenshots/ui-v2/P2/validation.md) | 下一节卡的课中、课前、跨日、结束、无课、预览、未开学和学期结束状态 |
| [P6 插画对比](P6-validation.md) | 固定场景的透明度选择过程 |
| [P7 操作入口](P7-validation.md) | 设置、按钮与点击区域 |
| [P8 时间线](P8-validation.md) | 课前、课中、课间、课后和切日、预览后的隐藏行为 |
| [P8.5 无障碍验收](P8.5-validation.md) | 对比度、动态字体、无障碍说明与系统栏 |
| [P9 完整验收](P9-validation.md) | 32 项完整真机检查、10 项时间线/布局检查和宽度字体矩阵 |
| [后续素材与课程卡验证](ICON-BACKGROUND-REFRESH-VALIDATION.md) | 图标、背景更新与单节进行中课程卡；补充 11 项布局/时间线回归 |

这些结果对应各记录描述的代码阶段。单节卡高度修复后跑过完整 32 项与 8 项状态矩阵；最后的两行倒计时调整追加了 354 / 411dp、130% 字体和原始宽度 100% 字体检查。后续发布的构建、压缩、签名和升级结果以对应 Release 说明为准。

历史记录明确保留未验证项，包括正式签名包升级、长时间待机或重启恢复、其他厂商硬件。正文对比度测量采用固定主色 preset 0；其他配色未逐一测量。
