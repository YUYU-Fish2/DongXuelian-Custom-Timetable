# Mein-Stundenplan 参考图对齐 Plan v2
## 在参考图对齐版基础上，补充“更换新的背景图标与课程表图标”的明确要求

> 用途：发给 Codex 直接执行  
> 适用范围：覆盖 `Mein-Stundenplan_Reference_Aligned_PLAN.md` 中与“背景图标 / 课程表图标”有关的旧要求  
> 原则：**不是只微调现有图标，而是允许并建议替换成一套新的、更统一、更贴近示例图气质的图标与装饰素材。**

---

# 0. 本次补充的核心意思

用户希望：

> **一些背景图标和课程表图标不要只修修补补，而是可以直接换成新的。**

所以从现在开始，Codex 在视觉执行时应采用以下原则：

```text
能换新，就不要只在旧图标上小修小补
```

尤其是以下两类内容：

1. **背景装饰图形 / 背景图标**
2. **课程表中的功能图标 / 信息图标**

如果旧素材和目标示例图气质不够接近，允许直接替换为：

```text
新的装饰素材
新的 VectorDrawable 图标
新的卡片插画
```

# 2. 新背景装饰素材的目标风格

## 2.1 Hero 区域背景装饰

Hero 背景中的装饰素材要比以前更完整，尽量采用新的素材组合：

```text
白花 / 蓝白花束
窗边垂落叶片
花瓶
桌面书本
翻开的书页
远景建筑 / 水面 / 天空
前景花瓣
```

### 风格要求

- 水彩感
- 柔光
- 清透
- 偏浅色
- 与蓝白主题协调
- 不要过分写实
- 不要用扁平 Material 装饰图形代替

### 位置要求

- 左上文本区背景要干净
- 右上人物区背景可以丰富
- Hero 底部装饰要与下一节卡过渡自然

---

## 2.2 页面下半部分背景装饰

不只是 Hero，页面中下部也应有新的氛围装饰。

可以换成：

```text
淡蓝花朵
模糊花瓣
柔焦书页
叶片
轻水彩晕染
```

要求：

- 作为氛围层
- 比课程卡更淡
- 不能遮挡信息
- 尽量分布在边缘、角落、底部

---

## 2.3 课程卡右侧插画

每张课程卡的右侧插画都允许重新换新。

优先统一为：

```text
书本 + 花束
或
花束 + 叶片
```

不同课程卡可以做同一套风格下的轻微变化：

```text
绿色卡：偏叶片 / 清新白花
粉色卡：偏浅桃粉花 + 书本
紫色卡：偏薰衣草 / 白花 + 书本
```

### 要求

- 同一套画风
- 都是淡彩
- 不要某张卡是书、某张卡是耳机、某张卡是杂物，题材风格要统一
- 插画在视觉上是“背景层”，不是主体

# 3. 课程表图标必须换成一套新的统一系统

从现在开始，课程表图标不建议继续“基于旧图标修一点点”。

而是建议：

> **重做成一套新的统一图标系统。**

---

## 3.1 新图标系统总规范

```text
24 × 24 viewport
1.8dp 标准描边
round line cap
round line join
几何简洁
轻盈、精致、柔和
```

其中：

- 工具型图标：1.8dp
- `plus`：2.0 ~ 2.1dp
- 小型 meta icon 实际显示尺寸：14dp
- Header action icon 实际显示尺寸：约 20dp

---

## 3.2 课程信息图标（重新绘制）

以下四颗图标建议直接换新：

### 时钟 `clock`
目标感觉：

```text
更细、更圆、更像示例图
```

### 定位 `location`
目标感觉：

```text
更轻、更简洁、底部尖角更柔和
```

### 人物 `person`
目标感觉：

```text
更简化，不要太粗太笨
```

### 日历 `calendar`
目标感觉：

```text
更轻的描边日历，顶部结构更简洁
```

这些图标共同要求：

- 比当前更统一
- 更接近示例图的轻描边风格
- 比辅助文字略深，但不要纯黑

---

## 3.3 操作类图标（重新绘制）

### More（三点）
直接换新。

要求：

```text
白色圆按钮保留
三个点更小
点与点间距更精致
更接近示例图
```

### Chevron Right
直接换成新的标准 outline chevron。

禁止再用 pointer 冒充。

### Settings / Tune
可以保留 slider/tune 概念，但建议重绘成更精致的新版本。

### Plus
保留蓝底白十字，但十字本身可重绘为更居中、更利落的新版本。

### Sparkle
如果当前版本不够精致，也允许换新，只要保持“浅蓝、轻提示、带一点梦幻感”的语义。

# 5. 背景装饰与课程图标的关系

换新时要记住：

> 背景装饰和课程图标不能抢同一层级。

必须满足：

```text
课程标题 > 时间/倒计时 > 图标/辅助信息 > 插画/背景装饰
```

这意味着：

- 图标应该清晰，但不能压过标题
- 背景装饰可以丰富，但必须更淡
- 课程卡右侧插画不能比 Meta 图标更抢眼
- Hero 背景可以丰富，但 Header 文字区域必须清楚

---

# 6. 背景与图标的配色方向

## 背景装饰配色

优先使用：

```text
白色
浅蓝
雾蓝
薄荷青
很淡的粉色
很淡的薰衣草紫
```

避免：

```text
高饱和红
高饱和黄
脏灰绿
过深棕
杂色过多
```

## 图标配色

优先使用：

```text
深蓝灰
柔和蓝
```

层级建议：

```text
标题文字      最深
图标          次深
辅助文字      略浅
装饰插画      更浅
背景          最浅
```

# 8. 对 Codex 的具体执行要求

Codex 在执行时不要理解成：

> “把旧图标略微改细一点就算完成”。

而要理解成：

> **如果旧图标或旧背景装饰不够好，就直接替换成新的。**

执行时应优先考虑：

1. 统一性
2. 参考图气质
3. 信息层级
4. 通透感
5. 梦幻蓝白风格

而不是优先保留旧素材。
